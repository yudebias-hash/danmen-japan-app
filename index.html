断面ジャパン管理

「断面ジャパン管理」は、YouTube チャンネル「断面ジャパン」の運営者が、自分のチャンネルを管理するためだけに使う道具です。一般の方が使うものではありません。

できること

  • 自分のチャンネルの動画の情報（タイトル・概要欄・タグ・公開設定）の確認と修正
  • 字幕の追加
  • 自分のチャンネルに届いたコメントの確認・返信・表示の管理
  • 自分のチャンネルの再生の統計（YouTube Analytics）の確認

YouTube Data API と YouTube Analytics API を、運営者本人の Google アカウントの許可のもとで使います。

プライバシーポリシー

About (English)

"Danmen Japan Kanri" is a private tool used only by the owner of the YouTube channel Danmen Japan to manage that channel: checking and updating video details, adding captions, reading and replying to comments on the channel, and viewing the channel's analytics. It uses the YouTube Data API and the YouTube Analytics API with the owner's own authorization. It is not offered to the public.
