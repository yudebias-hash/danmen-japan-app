プライバシーポリシー

制定日：2026年10月18日

「断面ジャパン管理」（以下「本ツール」）は、YouTube チャンネル「断面ジャパン」の運営者が、自分のチャンネルを管理するためだけに使う道具です。

1. 使う情報

本ツールは、YouTube API サービス（YouTube Data API・YouTube Analytics API）を通じて、運営者本人が許可した範囲で、次の情報を読み書きします。

  • 運営者のチャンネルと動画の情報（タイトル・概要欄・タグ・公開設定・字幕）
  • 運営者のチャンネルに投稿されたコメント（投稿者の表示名・本文を含む）
  • 運営者のチャンネルの統計（再生回数・視聴者の年齢層などの集計値）

2. 使い道

チャンネルの管理（動画の設定の確認と修正、コメントへの返信、統計の確認）にだけ使います。広告や、ほかの目的には使いません。

3. 保存と第三者への提供

取得した情報は、運営者のパソコンの中にだけ保存します。第三者に売ったり、渡したりすることはありません。

4. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティのアプリとサービス」の設定から、いつでも取り消せます。

5. YouTube と Google の規約

本ツールは YouTube API サービスを使っています。YouTube の利用にはYouTube 利用規約が、情報の扱いにはGoogle プライバシーポリシーが適用されます。

6. お問い合わせ

YouTube チャンネル「断面ジャパン」の運営者まで。

Privacy Policy (English)

Effective date: October 18, 2026.

"Danmen Japan Kanri" is a private tool used only by the owner of the YouTube channel Danmen Japan. Through the YouTube API Services (YouTube Data API and YouTube Analytics API), and only with the owner's own authorization, it reads and updates the owner's channel and video details (titles, descriptions, tags, visibility, captions), comments posted on the owner's channel (including commenters' display names and text), and aggregated analytics for the owner's channel. This data is used only to manage the channel, is stored only on the owner's computer, and is never sold or shared with third parties.
